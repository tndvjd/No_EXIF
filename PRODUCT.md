# Product

## Register

product

## Users

No EXIF Pro is a personal desktop workbench for a single AI image creator who uses ComfyUI and related image-generation workflows. The user works with local image batches, generated PNG metadata, prompts, model details, and privacy-sensitive EXIF data. The app should assume focused solo use, repeated daily actions, and a preference for fast command-driven workflows over decorative onboarding.

## Product Purpose

No EXIF Pro exists to make ComfyUI image cleanup fast, private, and reliable. It helps the user import generated images, inspect metadata, remove EXIF/privacy fields, organize images into grid exports, review prompt/workflow details, create prompt-share cards, and bring Pixiv or local image batches into one local workspace.

Success means the user can move from "I have a messy folder of generated images" to "I know what each image contains, what metadata is safe, and what I can export or share" without jumping between scripts, file explorers, and image viewers.

## Brand Personality

Clean, fast, private.

The product should feel like a quiet professional tool: sharp, immediate, and trustworthy. It should not feel like a marketing site, a toy utility, or a heavy creative suite. The interface should help the user stay in flow, with command-palette speed, clear privacy signals, and dense but legible information.

## Anti-references

- Purple/blue AI-gradient SaaS aesthetics, neon glow, aurora blobs, and generic "AI tool" visual language.
- Cute utility-app styling, playful emoji-heavy copy, and rounded cartoon-like controls.
- Heavy Photoshop-like tool chrome where every control competes for attention.
- Decorative motion that delays work or makes the app feel like a showcase instead of a tool.
- Generic glassmorphism, oversized cards, and gradients used as decoration rather than state.

## Design Principles

1. **Command first.** The fastest path should be search, command palette, keyboard shortcut, or a visible primary action.
2. **Canvas before chrome.** Image preview, grid canvas, prompt card preview, and metadata inspection are the product. Panels and navigation should support them quietly.
3. **Privacy is visible but calm.** Local processing and EXIF safety should be visible as trust signals, not fear-driven warnings.
4. **Density with discipline.** The app can be information-dense because the user is technical and task-focused, but every panel needs strong hierarchy and predictable grouping.
5. **Motion confirms state.** Premium motion is welcome when it explains transitions, command focus, selection, export completion, or error state. Motion must not become decoration.

## Accessibility & Inclusion

The UI should target accessible product-tool behavior: visible focus states, keyboard-first command access, legible Korean and English labels, sufficient text contrast, and no reliance on color alone for state. Motion can be polished and premium, but it must respect `prefers-reduced-motion` with shorter or crossfade alternatives.
