No EXIF Pro 확장 계획

Pixiv 크롤러는 기능만 가져오고, 앱은 그대로 유지합니다.

목표는 `pixiv_crawl` 프로젝트를 통째로 섞는 것이 아니라, Pixiv 이미지 수집 기능을 No EXIF Pro 안의 새 “Pixiv 가져오기” 탭으로 붙이는 것입니다. 기존 EXIF 제거, 그리드 생성, 메타데이터, 프롬프트 공유 흐름은 그대로 살립니다.

기능 병합 토큰 보호 다운로드 엔진 재사용 기존 앱 유지 검증 후 통합

한 줄 요약

  • 1Pixiv에서 이미지를 가져오는 엔진만 분리합니다.
  • 2Electron 앱 안에 새 탭으로 붙입니다.
  • 3받은 이미지는 No EXIF Pro의 기존 이미지 목록으로 들어갑니다.
  • 4토큰, 가상환경, 다운로드 폴더는 그대로 섞지 않습니다.

전체 구조

React 화면 사용자가 보는 새 Pixiv 탭입니다. 작가 URL, 저장 폴더, 다운로드 버튼을 다룹니다.
→
Electron IPC 화면과 Python 기능 사이의 인터폰입니다. 사용자의 명령을 안전하게 전달합니다.
→
Python Pixiv 엔진 Pixiv 로그인, 목록 조회, 이미지 다운로드를 처리하는 엔진룸입니다.

구현 순서

엔진 분리

`pixiv_crawl`의 `crawler.py` 기능을 No EXIF Pro용 `tools/pixiv_bridge.py`로 옮깁니다.

테스트 작성

URL 파싱, Pixiv 다운로드 헤더, 파일명 안전 처리부터 검증합니다.

앱 연결

Electron IPC를 추가해 React 화면에서 Python 엔진을 호출하게 합니다.

새 탭 추가

좌측 레일에 “Pixiv 가져오기” 탭을 만들고 다운로드 UI를 붙입니다.

QA

`npm run verify`와 실제 앱 실행으로 기존 기능이 깨지지 않았는지 확인합니다.

가져올 것

Pixiv 목록 조회

작가 ID나 URL을 입력하면 작품 목록과 다운로드 후보를 가져옵니다.

이미지 다운로드

이미 검증했던 Pixiv 앱 스타일 헤더를 사용해 `HTTP 403` 문제를 피합니다.

이미 받은 파일 스킵

같은 파일이 있으면 다시 받지 않고 건너뜁니다.

No EXIF 흐름 연결

다운로드한 이미지를 EXIF 제거, 메타데이터, 그리드, 프롬프트 공유에서 바로 사용합니다.

가져오지 않을 것

token.txt

계정 열쇠와 같아서 코드에 섞거나 복사하지 않습니다.

.venv

가상환경은 이삿짐 박스 전체 같은 것이라 프로젝트에 복사하지 않습니다.

downloads 폴더

이미 받은 이미지 창고입니다. 앱 기능 병합 대상이 아닙니다.

Streamlit UI

기존 Pixiv 웹 UI는 버리고, No EXIF Pro 안의 새 탭으로 다시 만듭니다.

주요 파일

tools/pixiv_bridge.py

Pixiv 로그인, 목록 조회, 다운로드를 담당하는 Python 엔진입니다.

pro-ui/src/PixivImportMode.jsx

사용자가 실제로 보게 될 Pixiv 가져오기 화면입니다.

electron/main.cjs

React 화면과 Python 엔진을 연결하는 Electron 쪽 통로입니다.

electron/preload.cjs

화면에서 안전하게 호출할 수 있는 기능 이름을 노출합니다.

tests/test_pixiv_bridge.py

Pixiv 엔진이 안전하게 동작하는지 확인하는 Python 테스트입니다.

tools/electron_qa.cjs

앱을 실제로 띄워 새 탭과 기존 기능을 확인하는 QA 스크립트입니다.

MVP와 이후 확장

MVP

작가 URL/ID 입력, 작품 목록 조회, 체크한 이미지만 다운로드, 다운로드한 이미지를 앱에 추가합니다.

2차

진행률, 실패 재시도, 일부 실패 목록, 저장 폴더 열기, 다운로드 결과 Toast를 다듬습니다.

3차

작가별 라이브러리, 태그 검색, 즐겨찾기, 다운로드 기록 DB를 검토합니다.

검증 기준

기존 기능 유지

EXIF 제거, 그리드 생성, 메타데이터, 프롬프트 공유가 계속 작동해야 합니다.

Pixiv 다운로드 성공

선택한 이미지만 저장되고, 이미 있는 파일은 스킵되어야 합니다.

토큰 미노출

Refresh Token이 로그, Toast, 테스트 출력, 저장 파일에 보이면 안 됩니다.

전체 테스트 통과

`npm run verify`가 통과해야 구현 완료로 봅니다.

쉬운 비유: 이번 병합은 두 집을 합치는 일이 아니라, 기존 집에 새 기계를 들여놓는 일에 가깝습니다. No EXIF Pro라는 집은 그대로 두고, Pixiv에서 이미지를 가져오는 기계만 안전하게 설치합니다. 자세한 개발자용 체크리스트는 원본 계획 문서에 남아 있습니다.
